# Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is a React-based online plant shopping application.

The application allows users to:

* Browse different categories of plants
* View plant images, names, and prices
* Add plants to a shopping cart
* Increase and decrease quantities
* Remove plants from the cart
* View the total cost of their purchases
* Navigate between Home, Plants, and Cart pages

## Technologies Used

* React
* Redux Toolkit
* React Redux
* React Router
* JavaScript
* CSS
* Vite

## Plant Categories

The application contains three plant categories:

1. Air Purifying Plants
2. Flowering Plants
3. Succulents

Each category contains at least six unique plants.

## Features

### Landing Page

The landing page displays the Paradise Nursery company name and provides a "Get Started" button.

### Product Listing

Users can browse plants grouped by category and add plants to their shopping cart.

### Shopping Cart

Users can:

* Increase quantity
* Decrease quantity
* Delete products
* View individual item totals
* View the overall cart total
* Continue shopping
* Checkout

The checkout functionality currently displays a "Coming Soon" message.
